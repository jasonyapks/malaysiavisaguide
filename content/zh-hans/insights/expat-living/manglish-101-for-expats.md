来马来西亚的第一周，就会有人问你“Can or not?”，然后等着你回答。同事会说要去“tapau”午餐，Grab 司机会说今天的塞车“very teruk one”。这些都算英语，可没有一句能在常用会话手册里找到。

这就是 Manglish，也就是马来西亚英语。它混合了英语、马来语、福建话、广东话和淡米尔语，各族马来西亚人都在说，银行经理下了班也不例外。下面整理的是你最常会听到的部分。

如果你会说中文，会发现其中不少词一点都不陌生。

## 句尾那几个小词，作用最大

Manglish 的语气，很大一部分靠句尾的短小语气词来表达。它们能做到标点符号做不到的事。一旦分得清它们，很多对话就突然听懂了。

{% table caption="必学的语气词" %}
| 语气词 | 作用 | 例句 |
| --- | --- | --- |
| **lah**（啦） | 视语气而定，可缓和，也可加强 | “Don't worry lah.” · “Come lah!” |
| **lor**（咯） | 无奈地接受 | “No more seats, so we stand lor.” |
| **meh**（咩） | 怀疑或惊讶 | “Got such thing meh?” |
| **mah**（嘛） | “这不是明摆着吗？” | “I told you already mah.” |
| **leh**（咧） | 轻轻催促，或小小抱怨 | “Help me a bit leh.” |
| **one** | 加强对事物的描述 | “This durian very nice one.” |

这些词没有必要背规则，因为这里谁都不按规则来。多听语气就好，一个月左右你就能听出区别。

## 每天都会听到的说法

**Can or not?** 意思是“行不行？”或“你愿不愿意？”。回答通常是“can”（可以）、“cannot”（不行），对方很乐意的话会说“can can”。

**Got or not?** 问的是“有没有？”。“Got”几乎处处取代了“have”和“is there”，比如“Got parking or not?”（有没有停车位？）。

**Where got?** 意思是“哪有，才没有”。你对朋友说“You so rich!”，多半会听到一句“Where got!”。

**Already** 表示事情已经做完，所以“I eat already”就是“我吃过了”。

**Is it?**（常写作“izzit”）是一种反应，大概等于“真的吗？”，并不是在问什么具体的事。

**Then how?** 意思是“那现在怎么办？”。

**Send** 指开车送人。“I send you to the airport”是好心要载你去机场，不是要把你寄出去。

**On the light** 和 **off the light** 就是开灯、关灯。住上一年，你自己也会这么说。

**Outstation** 指出城、去外地：“Boss is outstation this week.”（老板这周出差了。）

**Gostan** 指倒车。它来自旧时航海用语“go astern”（向后退），停车场管理员朝你喊的就是这个词。

## 吃的词

吃几乎算得上是全民爱好，所以点餐是 Manglish 最快派上用场的地方。

**Makan** 意思是吃，或者食物。“Jom makan!”（走，吃饭去！）是这篇文章里最有用的一句话。

**Tapau** 就是外带、打包。它源自广东话的“打包”，现在各族都在用。马来语的说法是 **bungkus**，意思一样。

**Mamak**（嘛嘛档）是 24 小时营业的印度穆斯林餐馆，相当于全国人民共用的客厅。半夜去一家，点一份 roti canai（印度煎饼）试试。

**Kurang manis** 意思是少糖。这里的饮料默认都很甜，所以你会经常用到这句。

**Boss** 是你对点单的人的称呼，并不代表谁是上级。

### 在咖啡店点饮料

Kopitiam（咖啡店）的饮料点法自成一套语法。先选基础饮料，再加上你想要的组合：

{% table caption="咖啡店饮料暗号" %}
| 点法 | 你会拿到的 |
| --- | --- |
| **Kopi / Teh** | 加炼奶的咖啡 / 茶（甜） |
| **Kopi O / Teh O** | 不加奶，加糖 |
| **Kopi C / Teh C** | 加淡奶和糖 |
| **…kosong** | 无糖 |
| **…peng / …ais** | 冰的 |
| **Teh tarik** | 拉茶，奶茶从高处来回倒，直到起泡 |

所以“kopi O kosong ais”就是无糖冰黑咖啡。说的时候别犹豫，柜台后面的 uncle 会以为你是熟客。

## 怎么称呼别人

马来西亚人很少直接叫陌生人的名字，通常用亲属称谓。

**Uncle** 和 **auntie** 可以用来称呼任何年长的男性或女性，比如小贩、邻居、保安。既礼貌又亲切。

**Abang** 和 **kakak** 是马来语的“哥哥”和“姐姐”，用来称呼和你年龄相仿或稍大一些的人。口语里会缩短成 **bang** 和 **kak**。

**Adik** 用来称呼比你年轻的人。服务员常被叫作“dik”。

**Boss** 可以称呼任何为你服务的人，前面已经说过。

## 情绪和反应

**Alamak!** 就是“糟了！”，打翻拉茶、错过出口、忘带钱包时都用得上。

**Aiyoh** 和 **aiyah** 表达无奈，可轻可重。

**Walao (eh)** 是福建话，表示难以置信，最常在塞车时听到。

**Paiseh** 也是福建话（歹势），意思是不好意思、麻烦你了：“Paiseh, can I sit here?”

**Kiasu**（怕输）就是怕吃亏。提前一个小时去排自助餐是 kiasu，“以防万一”买三把伞也是。

**Syok** 意思是爽、过瘾。一顿好饭是 syok，中午走了一段路之后吹到冷气也是。

**Kantoi** 意思是被抓包，说的人通常还带着笑。

**Teruk** 意思是很糟糕，多半用来形容塞车。

**Cincai** 意思是随便、马马虎虎：“Just cincai put there.”（随便放那儿就好。）

**Jom** 意思是走吧。“Jom lepak”就是走，出去坐坐。

**Lepak** 指没什么计划地闲坐、打发时间。嘛嘛档就是为这个而存在的。

**Belanja** 意思是请客。同事说“Today I belanja”，就是这顿他请，下一顿轮到你。

**Balik kampung** 意思是回乡。每到节日都会听到，紧接着城里的高速公路就空了。

## 几个让生活更方便的马来语单词

Manglish 从马来语借了很多词。学会下面这几个，大部分菜市场摊位和打车场合都能应付：

{% table caption="日常马来语" %}
| 马来语 | 意思 |
| --- | --- |
| **Terima kasih** | 谢谢 |
| **Sama-sama** | 不客气 |
| **Berapa?** | 多少钱？ |
| **Boleh** | 可以 |
| **Tak boleh** | 不可以 |
| **Sudah** | 已经、完了 |
| **Tumpang** | 借过（或者让我挤一下） |
| **Kanan / kiri** | 右 / 左 |
| **Sini / sana** | 这里 / 那里 |
| **Jalan** | 路，或者走路 |

## “lah”别加太多

外国人在恰当的地方说出一个“lah”，马来西亚人会很开心；说得勉强，他们也马上听得出来。先从真正用得上的几个开始：can、tapau、jom、kurang manis 和 terima kasih。其余的会慢慢学会。一年之后，说不定你会发现自己在叫国内的朋友“on the light”。

不过，学会这些词只是适应生活的一部分。如果你还在考虑哪种长期签证适合自己，可以先看看[我们对 MM2H、PVIP 和 DE Rantau 的比较](/insights/comparisons/mm2h-vs-pvip-vs-de-rantau/)。
