人人都说吉隆坡生活成本低。可当你去打听一所不错的国际学校附近的公寓价格时，数字却跟博客文章里写的完全不是一回事。这两种说法其实都没错。对大多数本地居民的生活方式而言，吉隆坡确实便宜。至于对你是否便宜，则取决于你尚未做出的几个决定，以及马来西亚只向非公民收取的几项费用。

你通常能找到的数字其实帮不上什么忙。它们往往是某个人几年前的预算，或者是把合租公寓里的学生与Mont Kiara的一家人混在一起算出的众包平均值。这两者都不是你。因此，我们编制了三份可能更贴近你的预算。

**简而言之：**截至2026年10月，一对退休夫妇在外籍人士聚居区的两居室公寓居住，健康保险费用之外，每月支出大约为RM7,500至RM8,500。一名独自生活的远程工作者，每月RM4,500至RM7,000即可过得不错。一个有两名孩子就读英式课程国际学校的家庭，每月需要RM26,000或以上，其中约三分之二用于支付学费。

## 吉隆坡普通家庭的实际支出

官方数字比看起来更值得作为出发点。马来西亚统计局在2024年的调查中指出，吉隆坡家庭平均每月支出为RM8,178，中位数家庭为RM6,789。只有布城（Putrajaya）的支出更高。吉隆坡的数字比全国平均水平RM5,566高出大约一半。

以下是这RM8,178的去向：

| 支出项目 | 每月支出（RM） | 占比 |
| --- | --- | --- |
| 住房、水电及燃气 | 2,497 | 30.5% |
| 外出用餐 | 1,346 | 16.5% |
| 在家饮食 | 976 | 11.9% |
| 交通 | 868 | 10.6% |
| 电话、网络及媒体 | 470 | 5.8% |
| 个人护理及其他杂项 | 466 | 5.7% |
| 保险及金融服务 | 417 | 5.1% |
| 家具及家居用品维护 | 348 | 4.3% |
| 娱乐与文化 | 298 | 3.6% |
| 医疗保健 | 170 | 2.1% |
| 服装及鞋类 | 141 | 1.7% |
| 烟酒 | 96 | 1.2% |
| 教育 | 84 | 1.0% |
| **总计** | **8,178** | **100%** |
[^1]: 马来西亚统计局（Department of Statistics Malaysia）,《2024年住户开支调查》（Household Expenditure Survey 2024）,表3.1。住房项目包含了拥有自住房屋家庭的估算租金，因此该数字高于大多数居民的实际现金支出。

对外籍人士而言，其中三项数字会严重偏离实际。住房项偏离，是因为你会在外籍人士聚居的少数地区租房，而不是在整个城市范围内租房。教育项偏离，是因为每月RM84是把大多数将孩子送入免费政府学校的家庭都计算在内后得出的平均值。医疗项偏离，是因为RM170的假设前提是你能以公民价格使用公立诊所。

至于其余项目，无论是日常杂货、外出用餐还是电话费，你支付的金额大致与当地人相同。这使得计算方法变得简单：我们保留DOSM日常开支项目的原始数据，仅对会发生变化的三项换上我们自己测算的数字。日常开支——即住房、交通、医疗、教育及保险以外的所有项目——合计为**每月约RM4,100**，这是吉隆坡一个家庭的数字。以下每项预算均以此为起点。

## 仅因你不是公民而产生的收费

这里说的不是诈骗，也不是市场小贩随口报出的“外国人价”。这些收费写入了法律或政策之中，而几乎没有一篇生活成本文章会提到它们。

- **私立医疗征收6%服务税。**自2025年7月1日起，私立医院和诊所对非公民的治疗费用征收服务税，马来西亚公民则获得豁免。海关（Customs Department）的常见问题解答明确指出，非公民中没有任何一类可以获得豁免，因此持有MM2H 第二家园计划或高端签证计划（PVIP）准证都没有区别。
- **年学费超过RM60,000的国际学校，学费须缴纳6%服务税。**在吉隆坡，大多数国际学校从一年级（Year 1）左右起就会超过这个门槛。
- **未获补贴价格的汽油。**在2026年10月22日至28日这一周，马来西亚人在BUDI95补贴下，RON95汽油每升支付RM1.99，而其他所有人则支付RM4.32。如果你拥有一辆车，这意味着价格超过两倍。
- **价格贵三倍的交通卡。** My50 卡以 RM50 的价格提供30天的火车和巴士无限次搭乘，但只有马来西亚人才能购买。对外籍人士开放的卡——Rapid Bulanan——价格为 RM150。
- **公立医院的全额费用。** 卫生部对外籍人士收费为：普通门诊 RM40，专科门诊 RM120，急诊 RM100。公民只需支付 RM1 至 RM5。
- **购房最低价格门槛更高。** 外籍人士在吉隆坡购房价格不得低于 RM1,000,000。在雪兰莪州，这一门槛为 RM2,000,000。

有一项费用你可以不必再担心：你的租金不征税。服务税已于2025年7月扩大至租赁范围，但海关的常见问题解答确认，住宅租赁不在征税范围之内。

## 预算一：退休夫妇

你已年过六十。你已经卖掉了家乡的房子，或是将其出租，现在想要一套带泳池、健身房和门卫的两居室公寓。

| 每月 | RM |
| --- | --- |
| 租金：两居室公寓，Mont Kiara | 2,800–3,200 |
| 日常开支（DOSM 基准） | 约 4,100 |
| 电费、水费、网络费 | 几百 |
| 市内交通：两张 Rapid Bulanan 月票，外加搭出租车 | 300多 |
| **不含医疗保障** | **约 7,500–8,500** |
[^2]: 租金数据取自2026年10月23日 Mont Kiara 35套两卧室单位标价租金区间的中间一半（中位数为RM3,000）。这是标价租金，并非实际成交租金。

这份预算是否可行，取决于表中没有列出的一项开支——医疗。年过60岁后，保险变得更贵也更难买到，而外籍人士支付的每一张私人医疗账单都要加收6%的服务税。

Mont Kiara 对你来说也可能超出实际需要。隔壁的 Sri Hartamas，两卧室单位标价在RM3,000至RM3,800之间；再往外，像 Cheras 这样的地区，标价约为RM2,100。

**适合的签证：** MM2H 白银级，没有收入要求。你转而存入{{mm2h-silver:fixedDeposit:money}} 的定期存款，并购买一套房产，该房产在吉隆坡价格须至少为RM1,000,000。一旦拥有房产，租金这一项即会消失，存款与房屋仍归你所有。按五年期准证摊算，各项费用每月约为RM700。 [MM2H 费用知多少](/insights/how-to/how-much-does-mm2h-cost/) 一文列出了完整费用清单。

## 预算二：有两个孩子的家庭

你因工作或生意而搬迁至此，你的孩子分别是七岁和十岁。

| 每月 | RM |
| --- | --- |
| 租金：三居室公寓，Mont Kiara | 3,500–5,800 |
| 学费：两名孩子就读于 Garden International School，含6% SST | 约17,700 |
| 日常支出（DOSM 基准） | 约4,100 |
| 一辆汽车，按未补贴汽油价格计算 | 1,000以上 |
| **不含医疗保障和学校额外费用** | **约26,000–29,000** |
[^3]: Garden International School 2026/27学年的学费为：3年级每年RM97,830，6年级每年RM102,300，两者均高于RM60,000的服务税起征点。校服、校车、餐费、游学及电子设备费用另计。租金部分取自2026年10月23日Mont Kiara地区65套三卧单位叫价租金的中间一半区间（中位数为RM4,300）。

看看学校这一行。 **它比表中其他项目加起来还要大。**大多数家庭通常先研究租金，但在这里，租金与学费相比几乎微不足道。换一所学校，这项预算每月上下可浮动RM10,000。槟城的Uplands学校3年级和4年级学费为每年RM46,400。对于同龄孩子，吉隆坡的ISKL收费为每年RM115,600，另加一次性注册费RM59,000。

**适合的签证：**如果是公司雇用你，则是工作准证（Employment Pass）。最低类别起薪为{{employment-pass:salaryFloor:money}}每月，但在指望用它养家之前，请确认你的类别允许携带受养人。如果你是靠自己的资金前来，可以考虑 MM2H 黄金级或高端签证计划（PVIP）。两者都允许更长的期限，并可携带家人，而高端签证计划（PVIP）还允许工作。在做出选择之前，请阅读[哪种马来西亚签证允许你经营企业？](/insights/comparisons/which-visa-lets-you-run-a-business/)

## 预算三：单身远程工作者

你为海外客户或雇主工作。你想要一间靠近咖啡馆和地铁线的一居室，并且不需要汽车。

| 月度 | RM |
| --- | --- |
| 租金：一居室，Mont Kiara 或 Sri Hartamas | 1,750–2,500 |
| 租金：一居室，Bangsar | 2,400–3,500 |
| 日常开支，一人 | 2,000–3,000 |
| Rapid Bulanan 月票，以及网约车 | 150以上 |
| 电费、水费、网络费 | 几百 |
| **不含医疗保障** | **约4,500–7,000** |
[^4]: 租金数据取自2026年10月23日一卧室求租广告价格的中间一半：Mont Kiara 24个房源，Sri Hartamas 34个，Bangsar 44个。日常开支线是估算值，而非实测值：根据马来西亚统计局（DOSM）的数据，吉隆坡普通家庭的日常开支约为每人RM1,600，而独居者的人均开支则高于这个数字。

**合适的签证：** DE Rantau 数字游民准证。它要求收入达到 {{de-rantau:incomeRequirement:moneyPer}}，按2026年10月的汇率计算，约为每月RM8,170。这几乎正好等同于吉隆坡普通家庭的开支水平。如果是一个人申请，最低门槛绰绰有余；但若带着伴侣，则难以维持Mont Kiara式的生活水平。该准证以一年为期，须逐年续签，也不能带来长期居留权。 [MM2H 第二家园计划 vs 高端签证计划（PVIP） vs DE Rantau 数字游民准证](/insights/comparisons/mm2h-vs-pvip-vs-de-rantau/) 说明了每种签证各自的局限。

## 预算容易出错的地方

人们计划的开支与实际花费之间的差距，大部分来自三个常见错误：

1. **按整个城市定价，而不是按社区定价。** 城市平均值涵盖了你根本不会居住的区域。靠近国际学校的两房单位，租金标价比切拉斯（Cheras）同类单位高出约一半。
2. **忘记计入只有外籍人士才需缴纳的税。** 这项6%的税费，会计入每一张私立医院账单和大多数国际学校学费中。这是实实在在的支出，而任何以马来西亚家庭数据为基础的平均值都不会把它计算在内。
3. **把医疗费用漏算在预算之外。** 没有哪一项开支会随着年龄增长变化得更剧烈，也没有哪一项会因为你是外籍人士而让你多付更多。请在签租约之前就把这笔费用算清楚，而不是等到第一张医院账单寄来之后。

所有这一切之下，还有汇率这个变量。本文所有数字均以林吉特计价。如果你以美元或英镑计收入，汇率百分之五的波动，也会让你的预算随之变动百分之五，因此做预算时应留出余地。

((所有数字均截至2026年10月23日。租金为某一时间点房源样本的标价租金，并非实际成交租金。学费为各校公布的2026/27学年收费标准。油价按周定价，每逢星期四调整。请在做出决定前核实最新规定。))
