在马来西亚纳税很容易，但令人惊讶的是，也很容易被错误地征税。这里的税率很低，减免很慷慨，而且在您跨过一条与您的签证毫无关系的界线之前，几乎没有任何税收适用于您。

您能找到的建议存在两个问题。第一个是时效性：大多数建议在发布时就冻结了，目前仍在流传的大量内容描述的都是2024年的情况。第二个是受众。马来西亚的税务指南是为马来西亚人编写的，因此它向您提供了一张减免表，其中数额最大的项目对于任何家人住在国外的人来说都是无法享受的，而且对于纯粹因为您持有外国护照而存在的规则只字未提。

以下是从您的角度对同一领域的解读。

## 一切都始于一个数字：182

您需要缴纳多少马来西亚税，几乎完全取决于您是否为税务居民，而税务居民身份是通过计算天数来决定的。在一个日历年内，在马来西亚停留182天或以上，您即成为居民。此外还有另外三种判定途径，其中一种甚至可以让您在从未踏足这里的年份成为居民，这些途径往往会使那些以为182天测试是唯一测试的人措手不及。

{% callout tone="warning" title="您的准证并不能决定这一点" %}
MM2H、PVIP或DE Rantau 数字游民准证赋予您在马来西亚停留的权利。它不会使您成为税务居民，也不会阻止您成为税务居民。大部分时间住在国外的准证持有人是非居民；而频繁持社交准证入境且不计算天数的访客则是居民。
{% endcallout %}

完整的四部分居民身份测试，以及您从海外汇入的资金会发生什么，均在我们的[海外收入与182天测试指南中有详细介绍](/insights/expat-living/is-foreign-income-taxed-in-malaysia/)。关于境外收入汇入的简要说明：对于居民个人，在境外已纳税的前提下，汇入马来西亚的境外收入在2036年12月31日前免税。对于非居民，则直接免税。这是马来西亚外籍人士税务中被误报最多的一条规则。如果您读到过“马来西亚现在对您的境外汇款征税”的说法，那您读到的是适用于企业的规则。

## 每种身份的实际成本

{% table caption="针对源自马来西亚收入的个人所得税" %}
|  | 居民 | 非居民 |
| --- | --- | --- |
| **税率** | 累进税率：RM 5,000以下免税，之后从1%起步，超过RM 2,000,000的部分升至30% | 单一税率**30%** |
| **个人减免** | 享有，适用完整减免表 | 无 |
| **税收回扣** | 享有 | 无 |
| **短期逗留免税** | 不适用 | 60天或以下，须符合条件 |

非居民损失的不仅仅是超额累进税率带来的优惠。他们还会失去所有的减免和回扣，这就是为什么这两种身份之间的实际差距比字面税率所显示的要大得多。一名年收入RM 250,000的居民在扣除减免后，实际支付的税率远低于30%；而同样收入的非居民则必须按30%的全额纳税。

{% callout tone="info" title="大多数短期工作者忽略的60天免税规定" %}
根据附表6第21段的规定，如果非居民在基准年内在马来西亚境内提供劳务的时间为**60天或以下**，其受雇收入可免税。如果逗留期跨越两个公历年，则两段时期需合并计算，且总计仍必须在60天或以下。

有三点需要注意：此规定不适用于居民公司的董事或公共艺人；它不是自动授予的——您必须在申报表中提出申请，并承担证明自己符合条件的举证责任；此外，它取决于在本地提供劳务的天数，而不仅仅是停留的天数。
{% endcallout %}

## 减免项目：外籍人士实际可以利用哪些

减免项目是居民身份通常值得拥有的原因，但公布的减免表是为马来西亚本地人撰写的。其中几项数额最大的减免是围绕与家人共同在马来西亚生活而设计的，它们悄然将典型的外籍人士排除在外。以下是YA2026的数据，按您实际获得的可能性进行了分类。

{% table caption="从外国居民角度看YA2026的减免项目" %}
| 减免项目 | 上限 | 外籍人士是否适用？ |
| --- | --- | --- |
| **个人（自动）** | RM9,000 | 是，无需申报即可获得 |
| **医疗——本人、配偶、子女** | RM10,000 | 是 |
| **生活方式** —— 书籍、设备、宽带、课程 | RM2,500 | 是 |
| **教育及医疗保险** —— 本人、配偶或子女 | RM4,000 | 是 |
| **体育** —— 器材、场地、健身房、教练 | RM1,000 | 是 |
| **个人学费** —— 经批准的课程 | RM7,000 | 是 |
| **育儿** —— 12岁及以下子女 | RM3,000 | 仅限在社会福利局（JKM）或州政府注册的中心 |
| **国内旅游** —— 景点及文化活动 | RM1,000 | 可能，但请参见下文 |
| **医疗服务 — 父母** | RM8,000 | 几乎从未 |

其中有三项需要解释，因为外籍人士往往在这些项目上超额申报或遗漏资金。

**RM10,000 的医疗上限是一个总上限。** 牙科检查和治疗在此额度内占 RM1,000，疫苗接种占 RM1,000，而全面体检、新冠肺炎（COVID-19）筛查和心理健康咨询共用另外的 RM1,000。严重疾病和生育治疗同样从这 RM10,000 中扣除。这些是子限额，而非额外额度，将它们视为独立减免是马来西亚报税表中最常见的超额申报错误。

**父母的减免并不适用于大多数外籍人士。** 马来西亚内陆税收局（LHDN）的条件非常明确：您的父母必须是**马来西亚居民**，且治疗或护理必须是**在马来西亚提供**，并由在马来西亚医学委员会、马来西亚牙医委员会、国家药品管理局（NPRA）或卫生部注册的执业医生证明。如果您的父母住在曼彻斯特或墨尔本，无论账单金额多大，您都无法享受这 RM8,000 的减免。只有在您将父母也移居到这里时，这才会成为现实。

**国内旅游是一项为期一年的激励措施。** 这是根据第 46(1)(sa) 条在 YA2026 新增的项目，涵盖博物馆、主题公园、国家和海洋公园、动物园、地质公园以及文化项目的门票。LHDN 将其定位为对 2026年马来西亚旅游年 的支持。该减免适用于一般的居民个人，因此居民外籍人士应该符合资格，但条文起草较为宽泛，在您依赖它之前值得进一步确认。

## 两条仅因您是外籍人士而存在的规则

这些是任何国内税务指南都不会为您标出的规则，而且这两条规则都曾让不少人陷入困境。

**公积金（EPF）不再是自愿性的。** 自 2025年10月 的工资起，非马来西亚公民雇员必须缴纳 EPF，比例为**雇主缴纳 2%，雇员缴纳 2%**。这适用于持有有效护照和准证的 75 岁以下非公民（家庭佣工除外），且没有过渡期 — 从第一个月起即适用完整的 2%。如果您的雇佣合同在此之前协商并引用了净额，那么计算方式已经发生变化。

{% callout tone="warning" title="税收清算：让人们滞留在机场的那一关" %}
如果您离开马来西亚超过三个月，您的雇主必须在您**离开前至少 30 天**向 LHDN 提交**CP21 表格**，并预计扣留您的最后一个月薪资和福利，直到税收清算信退回或 90 天过去（以较早者为准）。在材料齐全的情况下，清算本身大约需要 14 个工作日，且自 2024年1月1日 起，CP21 已成为仅限通过 MyTax e-SPC 进行的在线提交。

请将此视为一个流程，而非走过场。辞职、履行一个月的通知期并在期满后飞离，并没有留出足够的缓冲时间，而被扣留的资金是您自己的钱。在您决定离开的那一周，而不是在您打包行李的那一周，就开始与您的雇主讨论税收清算事宜。
{% endcallout %}

## 2% 的股息税

自 YA2025 起新增，且在外籍人士指南中基本未提及。个人股东（无论是否为居民）需对**超过 RM100,000 的股息收入缴纳 2%** 一年。首个 RM100,000 免税，该税项在您的申报表中自行申报。

免税项目涵盖了大部分情况。来自 EPF、LTAT、ASNB 和单位信托的股息不在此列，来自合作社和享有新兴工业地位（pioneer-status）公司的股息也是如此。外源股息同样不在此列，而是遵循汇入规则。在实践中，这主要影响到从马来西亚私人公司获取大额股息的人士，而这恰恰是许多在此的外籍商业所有者所使用的结构。

## 出售资产：您实际适用哪种税

这是已发布的建议最常出错的地方，因为马来西亚在 2024 年引入了资本利得税，而相关报道很少说明其适用于谁。

**出售房产：产业盈利税（Real Property Gains Tax）。** 这是适用于个人的税项。对于非永久居民的非公民，产业盈利税为**在购买后五年内处置所获收益的 30%，从第六年起为 10%**。马来西亚公民和永久居民在五年后税率递减至 0%。外籍人士则不然——10% 是永久底线，任何持有期限、准证或结构都无法免除。请在购买前而非购买后将此因素纳入收益率计算中。

**出售股份：资本利得税，这是一种公司税。** 自 1 January 2024 起生效的制度对处置马来西亚非上市公司的股份净收益征收 10% 的税，对于 2024 年之前持有的资产，可选择按总对价的 2% 征税，申报截止日期为处置之日起 60 天内。纳税义务人为公司、有限责任合伙企业、信托团体和合作社。**个人不是纳税义务人。** 以您个人名义持有股份，这便不会影响到您。

{% callout tone="warning" title="公司规则何时会成为您的问题" %}
第 15C 条透视了境外结构。如果处置了在马来西亚境外注册成立的受控公司的股份，且马来西亚不动产占其有形资产总额的 75% 或以上，则该收益被视为源自马来西亚并在本地征税——即使该交易发生在境外的外国实体之间。

作为私人个人，您不受此限制。但一旦您通过外国公司或信托持有马来西亚房产，您就会受到该条款的约束，而许多人在这样做时从未想过自己是公司纳税人。如果这符合您的情况，60 天的申报时钟是真实存在的，且逾期罚款并非自由裁量。
{% endcallout %}

## 如果您运营一家马来西亚公司：20% 所有权测试

马来西亚中小企业通常对其首个 RM150,000 的应税收入享受 15% 的优惠税率，对随后的 RM450,000 享受 17% 的优惠税率。自 YA2024 起，如果公司**超过 20%**的实收资本或资本出资由外国公司或非马来西亚公民的个人直接或间接拥有，则无法享受该优惠待遇。

在刚好 20% 时，您保留优惠税率；超过 20% 时，您将失去优惠，并全程支付 24% 的税率。这是在外籍所有者下最容易发生变化而无人察觉的规则，因为它影响的是股权结构表，而不是任何体现在贸易中的内容。如果您自成立以来引入了外籍合伙人或进行了重组，请检查持股情况，而不要假设去年适用的税率仍然适用。

## 清单

- **计算您的天数。** 182 天是门槛，但另外三项测试也可以使您成为居民。请跟踪日历，而不是在 4 月份去重新拼凑。
- **检查 60 天免税期** 如果您在此进行短期工作，并保留申请免税的证据。
- **不要重复计算医疗减免。** 牙科、疫苗接种和体检是 RM10,000 限额内的子限额，而不是其额外增加的部分。
- **扣除父母的减免额** 除非您的父母居住在马来西亚并在本地接受治疗。国外的账单不予受理。
- **检查您的工资单是否有 2% 的 EPF 扣除额**如果您在此处受雇——自2025年10月起，这已成为非公民的强制性要求。
- **请在离职前办理清税手续，而不是在离职后。**CP21 表格须在离境前30天提交，您的最后一笔薪资将被扣留，直至收到清税信。
- **在购买房产前，请先估算 RPGT。**对于非公民，五年内为 30%，此后一直为 10%。
- **如果您通过公司或信托持有马来西亚房产，**请就 Section 15C 寻求建议，并记录 60 天的申报窗口期。
- **检查您的股权结构表**以确认外国股东的持股比例是否可能超过 20%。
