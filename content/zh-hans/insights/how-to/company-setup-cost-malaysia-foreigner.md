您问了三家代理行在马来西亚开公司要花多少钱，得到了三个版本相同的答案："从 RM2,500 起"。这话没错，但几乎毫无用处。注册费是账单上最便宜的一项，而给出这个报价的代理行对此心知肚明。

有一点很少有人写出来。对外籍业主来说，真正决定一切的数字通常根本不是什么费用，而是公司在为您本人的工作准证提供担保之前必须持有的 RM500,000 资本。如果您需要这份准证，问题就不是您能否负担 RM2,500；如果不需要，您或许能用不到 Mont Kiara 一个月租金的钱，把整件事办完。

**简短的答案是：**注册一家马来西亚私人有限公司的费用约为 RM1,600 至 RM3,100，其中包括 RM1,000 的政府费用。对外籍业主而言，第一年的实际成本：如果您已持有允许从事商业活动的准证并在马来西亚居住，约为 RM5,000；如果需要委任一名常驻董事，则为 RM15,000–26,000；如果公司必须为您的工作准证提供担保，还需额外准备 RM500,000 或以上的资本。

## 您属于哪一类创办人？

设立马来西亚公司的外籍人士大致分为三类，他们为同一张证书支付的金额却相差甚远，因此先弄清楚自己属于哪一类。

**您将继续留在国外。**您希望用一家马来西亚公司向区域客户开具发票、持有合同或试探市场，但您本人并不打算搬到这里。您不需要签证，但您的董事会中必须有一位居住在马来西亚的成员，这才是您最大的成本所在。

**您打算搬到这里来经营公司。**您希望由这家公司雇用您本人，这意味着公司必须为您的工作准证（Employment Pass）提供担保。这就带来了资本金要求；而在您成为居民之前的最初几个月，还需要一位常驻董事。

**您已经居住在这里。**您本人持有一份允许从事商业活动的准证。您可以自己担任常驻董事，公司也无需为任何人提供担保。这是成本最低的一类，而且差距很大，只是身处其中的大多数人并没意识到自己省下了多少钱。

## 各类创办人第一年各需支付多少

所有数字均以林吉特计算，未计8%服务税。政府费用为确切金额。服务费用为参考区间，依据已公开的价目表以及两家马来西亚企业服务机构提供的书面报价得出，于2026年10月审核；建议自行索取报价。

|  | 您留在海外 | 您持工作准证（Employment Pass）移居至此 | 您已在此定居 |
| --- | --- | --- | --- |
| **公司注册，包含RM1,000的SSM费用** | 1,600–3,100 | 1,600–3,100 | 1,600–3,100 |
| **公司秘书** | 1,200–2,000 | 1,200–2,000 | 1,200–2,000 |
| **常驻（名义）董事** | 约10,000 | 约6,500，为期六个月 | 无——由您本人担任 |
| **可退还的名义董事保证金** | 约5,000 | 约5,000 | 无 |
| **营业地址** | 700起 | 700起，或使用您自己的办公室 | 700起，或使用您自己的住所 |
| **簿记与账目** | 1,000–6,600 | 约 6,600 | 1,000–6,600 |
| **审计（如不获豁免）** | 1,000–2,500 | 1,200–2,500 | 1,000–2,500 |
| **公司报税** | 700–1,200 | 900–1,200 | 700–1,200 |
| **薪资登记** | 不需要 | 约 600 | 仅在雇用员工时才需要 |
| **第二年起需提交年度报表及其他文件** | 500–1,000 | 500–1,000 | 500–1,000 |
| **公司必须持有的实缴资本** | 无最低限额规定 | 500,000，从事贸易业务则为 1,000,000 | 无最低限额规定 |
| **第一年大致费用** | **15,000–26,000** | **18,000–24,000** | **5,000–16,000** |

有两点值得注意。注册公司这一项费用在每一栏中都相同，而对于需要常驻董事的人来说，这只占总账单中的一小部分。至于各栏之间的差距，则取决于一个问题：是否已有一位董事居住在马来西亚？

## 常驻董事规定

SSM 的规定很简短。一家私人有限公司必须至少有一名常驻董事，即其主要居所设在马来西亚。规定中并未提及国籍。真正居住在马来西亚的外籍人士符合这一条件，而居住在伦敦的马来西亚人则不符合。

如果您居住在海外，有两个选择。可以请马来西亚的商业伙伴或可信联系人担任这一职位；也可以向服务提供商付费聘请名义董事，设立费用通常约为 RM3,000，每月约 RM600，一般附带最低合约期限，以及约 RM5,000 的可退还押金。

必须清楚名义董事究竟意味着什么。此人是马来西亚法律下真正的董事，拥有真实的职责与真实的签署权力，并为一家自己无法掌控的公司承担个人责任。这正是费用高昂的原因，也是一家信誉良好的服务提供商会要求押金、限制银行授权范围，并审视公司实际业务内容的原因。一个不多过问的名义董事，看似划算，实则并非如此。

如果您正打算移居此地，名义董事只需维持到您本人取得居民身份为止。按六个月预算，到期后即可更换。

## 实缴资本：并非一笔费用的数字

就注册公司而言，资本只是一项形式要求。真正令人望而生畏的数字来自别处——马来西亚移民局的外籍人士服务部门（Expatriate Services Division），公司在聘用任何外籍人士（包括其所有人）之前，都必须先在该部门登记。

| 公司的所有权归谁 | ESD要求的实缴资本 |
| --- | --- |
| 100%马来西亚人持股 | RM250,000 |
| 含外资股权的合资企业 | RM350,000 |
| 100%外资持股 | RM500,000 |
| 外资持股，经营批发、零售及贸易业务 | RM1,000,000 |

实缴资本是您自己的钱，存在公司账户里，公司可以动用它来维持日常运营。但这笔钱必须真实存在，而且您不能悄悄把它取回来。如果您是即将搬来这里的创办人，这就是您进入市场的真实成本。要按RM500,000来规划，而不是RM2,500。

## 无人提及的成本

**一切均需缴纳服务税。** 专业服务费需缴纳8%的服务税。请将其计入表格中的每一项服务费用。

**贸易执照。** 如果您的外资公司从事商品销售、进口分销，或经营商店、咖啡馆或餐厅，就须遵守国内贸易部关于外资参与分销贸易的规定。无论您持有哪种准证，开业前都须获得该部批准，并缴足RM1,000,000的实缴资本。该部表示相关准则正在检讨中，因此请在签署租约前查核最新版本。

**您享受不到的税率。** 马来西亚的小型公司首RM600,000利润按15%和17%纳税。外资持股超过20%的公司不符合资格，须从第一令吉起按24%纳税。我们在[外籍人士马来西亚税务指南](/insights/expat-living/malaysian-tax-for-expats/)中解释了这项判定标准。

**审计。** 私人公司如在营业额、资产和员工人数三项规模测试中符合其中两项，现可免于审计，其中营业额测试标准为：2026年起的财政年度为RM2,000,000，2027年起为RM3,000,000。请让您的公司秘书确认是否符合资格。若不符合，小型公司的审计费用约为RM1,200至RM2,500。无论是否获豁免，您每年仍须提交账目和报税表。

**年度申报。** 有些机构会将年度报表和账目备案一并计入公司秘书的聘用费中。另一些机构则会另行收费，从第二年起每年约增加RM500至RM1,000。在比较两家的月费报价之前，请先确认对方的报价是否包含这些项目。

**事后变更。** 委任或解任董事、迁移注册地址、转让股份及增资，在基础秘书服务方案下均需单独收费，每次通常为RM250至RM750。在第一年内更换名义董事并注资的创办人，会用到其中多项服务。

## 事情发生的顺序

1. **预留公司名称并注册成立。** SSM预留名称收费RM50，注册成立收费RM1,000。资料齐备的申请通常在数个工作日内获批。
2. **委任公司秘书** 须在注册成立后30天内完成。实际操作中，为您办理注册的机构通常会在当天完成此事。
3. **开立银行账户。** 对外籍股东而言，这是最耗时的一步。银行需要了解董事身份及资金来源，许多银行还要求与董事本人会面。应预留数周而非数天的时间。
4. **缴入资本** 并由公司秘书记录股份分配。
5. **取得相关执照。** 大多数实体业务需要地方议会的营业执照，若从事分销贸易，还需贸易部的批准。
6. **向 ESD 登记并申请准证，** 如果公司担保您。只有到这一步，工作准证（Employment Pass）的申请才真正开始。

需要申请准证的创始人，应以“月”为单位来看待整个流程。

## 公司不等于签证

这是代价最大的误解。拥有一家马来西亚公司，并不赋予您在马来西亚居留的权利，也不赋予您在自己公司工作的权利。这些权利来自准证，而持有准证有两种方式。

公司可以为您担保工作准证（Employment Pass），这正是上文资本要求的用途所在。最低一档要求月薪至少为 {{employment-pass:salaryFloor:money}} 一个月，该准证将您的居留权与这家公司绑定。如果公司倒闭，准证也随之失效。

或者，您也可以以自己的名义持有一种允许从事商业活动的居留准证。以下是本站各签证计划指南中对工作权利的记录方式：

| 准证 | 工作与商业权利 |
| --- | --- |
| 高端签证计划（PVIP） | {{pvip:workRights:text}} |
| MM2H 白金级 | {{mm2h-platinum:workRights:text}} |
| MM2H 黄金级 | {{mm2h-gold:workRights:text}} |
| MM2H 白银级 | {{mm2h-silver:workRights:text}} |

这就是为什么成本表第三栏的价格低得多。居住在马来西亚的PVIP或MM2H 白金级持有人可自任常驻董事，无需公司为任何人提供担保，因此名义董事和ESD资本要求均不适用。代价在于签证本身的费用：PVIP要求的定期存款为{{pvip:fixedDeposit:money}}，参与费为{{pvip:participationFee.principal:money}}。我们在[MM2H 白金级与PVIP对比](/insights/comparisons/mm2h-platinum-vs-pvip/)一文中比较了两者。

大多数MM2H持有人处于白银级或黄金级。如果您也是如此，在自任任何公司董事之前，请先核实自己的工作权利。

## 那么，您属于哪一种？

如果您**长期居留海外**，第一年预算为 RM15,000 至 RM26,000，外加一笔可退还的押金，把精力放在挑选当地董事（resident director）上，而不是放在寻找最便宜的注册代理上。

如果您打算**搬到这里来经营公司**,那么您真正要考虑的数字是 RM500,000 的资本，若从事贸易、零售或餐饮则是 RM1,000,000。与这个数字相比，各项费用只是零头。先想清楚这项生意是否值得投入这笔资本，再去注册公司。

如果您**已经持有可以在本地经商的准证**，那么您要准备的是 RM5,000 至 RM16,000，且没有资本门槛——除非您要从事分销贸易。您是唯一一个"从 RM2,500 起"这句话几乎说得过去的人。

而如果您还没有确定该申请哪种准证，就该带着这项生意去选。马来西亚最便宜的公司，属于那些先解决好自己居留身份的创办人。

法规与费用会变动。以上政府数据已对照下列官方来源，核实至 2026 年10月10日；请在做出决定前自行核实，并取得书面报价。
