年满50岁会改变MM2H规则中的一条，也正是50岁以上人士最为担心的一条：从这一生日起，每年须在马来西亚停留的最低天数不再适用。其余一切——从存款到房产，从各项费用到文件手续——都与30岁申请人完全相同。

这使MM2H特别适合把退休生活分摊在两个国家的人士。这同样意味着，真正涉及金钱的决定——选哪一档、在哪个州购置房产、携带多少名家庭成员——与较年轻的申请人所面对的完全相同。

## 50岁以上MM2H申请人有何不同：最低停留天数

MOTAC的指南按年龄而非按级别设定停留规则，且仅适用于年龄在50岁以下的参与者（第19页）。原文如下：{{mm2h-silver:minStayPerYear:text}}

对于年满50岁及以上的申请人，这带来两项实际影响。

- **允许一年中只停留部分时间的生活方式。**如果你打算北半球冬季在槟城（Penang）度过，夏季回到家乡，或是根据家庭安排随意往返，该准证都不要求你计算停留天数。
- **你的税务状况是另一项需要单独评估的问题。** 持有该准证并不意味着您成为马来西亚税务居民，而没有最低停留天数要求也不能阻止您成为税务居民。居民身份取决于您在本地停留的天数。我们在[属地原则与182天测试](/insights/expat-living/is-foreign-income-taxed-in-malaysia/)。

## 50岁时，哪些保持不变

没有最低停留天数要求，很容易被误读为“MM2H 第二家园计划可以完全在境外办理”。事实并非如此。无论申请人年龄多大，都有若干步骤必须本人亲自在马来西亚完成。

1. **获批后，须在境内完成的步骤。** 根据旅游、艺术及文化部（MOTAC）的流程图，申请人须在获批信发出后的规定期限内，备齐定期存款证明、（如适用）健康保险、体检报告、个人保证书及有效护照，然后缴纳相关费用并完成准证签发手续（第23页）。定期存款须存入马来西亚银行账户，体检须在指定诊所进行，因此这趟行程必须亲自前往，无法委托他人代办。
2. **购置房产。** 获批后，所有级别均须购置房产，且该房产十年内不得出售，除非换购价值更高的房产（第20页）。购房须在准证签发后一年内完成。 ((MYPVIP惯例，截至2026年8月3日))
3. **续签。** 实际操作中，续签申请须在您本人身处马来西亚时提交，因为申请需要附上您最近一次马来西亚入境章的复印件，以及最新的定期存款余额证明，并需在马来西亚诊所完成MF II表格的体检。 ((MYPVIP 操作惯例，截至2026年7月))使用自动通关系统（e-gate）的申请人应尽早提出入境印章的问题，因为经e-gate入境不会留下印章。

最低年龄要求同样维持不变，对年长申请人而言也无关紧要：旅游、艺术及文化部（MOTAC）将其设定为{{mm2h-silver:minAge:number}}，适用于白银级、黄金级和白金级，且未设上限（第17页）。

## 50岁以上的退休人士适合MM2H 第二家园计划的哪一级？

对大多数退休人士而言，选择主要在白银级与黄金级之间。白金级的独特之处在于，它是唯一允许在马来西亚工作或经营业务的级别，也是唯一允许携带外籍家庭佣工的级别（第20页）。如果您已经退休，且这两项权限都不需要，那么您支付的只是用不上的权限。

**白银级**的资金门槛最低，签证期限也最短，为{{mm2h-silver:tenureYears:years}}。需要提前规划的关键在于，购房条件的期限比这还长：你必须持有该房产满十年，因此在第一年购房的白银级参与者，其购房义务所持续的时间会比首个签证期限更长。如果你打算续签，这是一笔划得来的安排；但如果你把 MM2H 当作一次五年的尝试，这就不太划算了。

**黄金级**的签证期限为{{mm2h-gold:tenureYears:years}}，足以覆盖十年的持有期并留有余地，同时将定期存款提高至{{mm2h-gold:fixedDeposit:money}}。对于计划长期退休、五十多岁的夫妇而言，黄金级的期限比白银级更契合购房义务。

**白金级**的签证期限为{{mm2h-platinum:tenureYears:years}}，并需缴纳{{mm2h-platinum:participationFee.principal:money}}的参与费。这适合年满50岁、仍打算在马来西亚工作、投资或经营公司的申请人。若只是单纯为了退休，这是购买你并不需要的权利中最昂贵的方式。

SEZ 和 SFZ 区域路线是 MM2H 中唯一定期存款额本身从50岁起便有所降低的部分。它们要求你在指定开发项目内按该项目的价格购房，且相关数据所依据的是实际操作，而非 MOTAC 的类别表。相关内容见[2026年如何申请 MM2H](/insights/how-to/apply-for-mm2h-2026/)。

## 年满50岁后通过 MM2H 第二家园计划携带配偶或父母

MOTAC's guide 的指南允许参与者携带配偶、在年龄限制内的子女，以及父母和配偶的父母，而对父母并未设定年龄上限（第20页）。对于年满50岁以上的申请人而言，配偶和父母通常是名单上相关的人选。

受养人带来的是额外费用，而非资本要求。该指南规定受养人无需缴纳参与费（第18页），定期存款和房产则是申请人本人的要求。每名受养人还需额外承担：

- 一笔处理费，金额为 {{mm2h-silver:processingFee.dependant:money}}；
- 一笔准证费，金额为 {{mm2h-silver:passFeePerYear.dependant:money}} ，按批准期限的每一年计算，须在批准阶段一次性缴纳，而非逐年缴付；
- 一笔依受养人国籍而定的多次入境签证费，以及一笔金额较小的一次性保证金；
- 获批后须在指定诊所完成强制体检（第19页），并在年龄规定要求的情况下购买健康保险。

政府规定的代理费已涵盖首位受养人。自第二位受养人起，每人须另付一笔代理费。 ((MYPVIP，摘自政府 MM2H 第二家园计划收费表，截至2026年7月28日))

有一项规定值得夫妇留意。根据该指南，申请人身故后，其准证可转让给登记受养人中的直系亲属（白银级，第36页）。因此，若配偶在原申请中即以受养人身份列入，其处境将明显优于另行申请的配偶。

## 医疗保险与60岁后的体检

共有两项健康要求，两者常被混淆。

- **体检在任何年龄均属强制。** 旅游、艺术及文化部（MOTAC）要求申请人及每位受养人在获批后，前往该部指定的诊所或医院接受体检（第19页）。
- **年龄在60岁及以下的申请人须投保健康保险。** 旅游、艺术及文化部（MOTAC）的文件清单正是如此表述（第23页），承保人可为马来西亚本地或外国保险公司，只要保障范围覆盖全球即可。年满60岁以上的申请人在申请阶段则不受此项要求约束。

第二点有两处需留意。该指南的续签清单要求提供健康保险，但未重复年龄限定条件（第24页）。而且，指南并未明确说明年龄标准是分别适用于每位受养人，还是以申请人的年龄为准。若申请人年满60岁以上而配偶未满60岁，建议双方一开始就以书面形式明确谁需要投保，以及在哪个阶段投保。

## 申请是否需要养老金或收入？

MM2H 第二家园计划的任何级别均无收入要求，这也是该计划适合财富以储蓄及房产为主、而非以每月固定收入计算的退休人士的主要原因之一。这是官方公开的立场，但也容易被过度解读。

## 实例说明：选择白银级或黄金级的退休夫妇

以一对夫妇为例：主申请人66岁，配偶63岁，两人均靠养老金和储蓄生活。他们计划每年在马来西亚居住约五个月，其余时间留在本国，并打算购买一套公寓。两人均不会工作。配偶以受养人身份加入申请，申请中没有其他人。

|  | 白银级 | 黄金级 |
| --- | --- | --- |
| **定期存款（资金仍属您本人）** | {{mm2h-silver:fixedDeposit:money}} [^1] | {{mm2h-gold:fixedDeposit:money}} |
| **房产（成为您的资产）** | 低至{{mm2h-silver:propertyPurchaseMin:money}} [^2] | 起{{mm2h-gold:propertyPurchaseMin:money}} |
| **参与费，每份申请** | {{mm2h-silver:participationFee.principal:money}} | {{mm2h-gold:participationFee.principal:money}} |
| **代理费，涵盖配偶作为首位受养人** | {{mm2h-silver:agencyFee.principal:money}} | {{mm2h-gold:agencyFee.principal:money}} |
| **配偶的审理费** | {{mm2h-silver:processingFee.dependant:money}} | {{mm2h-gold:processingFee.dependant:money}} |
| **配偶的准证费，按批准年数计** | {{mm2h-silver:passFeePerYear.dependant:money}} | {{mm2h-gold:passFeePerYear.dependant:money}} |
| **配偶的签证费及保证金** | 按国籍 | 按国籍 |
| **在马来西亚停留天数要求** | 无 | 无 |
| **医疗保险** | 两者在申请时均无此要求 [^3] | 两者在申请时均无此要求 |
[^1]: {{mm2h-silver:fixedDepositWithdrawable:text}}
[^2]: {{mm2h-silver:propertyStateFloorNote:text}}
[^3]: 两人均已超过60岁，而旅游、艺术及文化部（MOTAC）的文件清单正是以此年龄作为保险要求的适用门槛（第23页）。续签清单在要求提供健康保险时并未附加此年龄限制（第24页），因此除非收到书面的其他说明，否则应从首次续签起就预留保险费用。

请分三层来看这张表格。定期存款仍是这对夫妇自己的资金，一旦签证获批，其中最多一半可凭已签署的购房协议，或凭在马来西亚境内的医疗、教育或旅游支出申请取回。房产属于资产，但表中所列的最低金额，在套用各州的门槛后，往往并非他们最终支付的价格。唯有各项费用才是真正的成本，而在两个级别中，费用都以代理费为主，而非参与费。

对这对夫妇而言，关键问题不在费用项目，而在于他们是否愿意将资金锁定{{mm2h-silver:tenureYears:years}}年，房产须保留满十年；还是锁定{{mm2h-gold:tenureYears:years}}年，而房产义务可完全在准证有效期内完成。无论选择哪一档，五个月的居留模式都可行，因为以他们的年龄，两档均无最低居留天数要求。

若要为自己的家庭（包括父母）核算各项费用总额，请使用[费用计算器](/tools/cost-calculator/)。该工具会单独计算每位受养人的费用，并将定期存款与房产同其他费用分开列示。
